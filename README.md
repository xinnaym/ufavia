## ✈ О проекте

**UFAvia** — региональный и федеральный интернет-сервис поиска, сравнения цен и онлайн-бронирования авиабилетов из Уфы и других городов России и мира.  
Сайт разработан в строгом соответствии с требованиями ТЗ:
- 7 ключевых страниц по ТЗ + полнофункциональная панель администратора;
- Интерактивный поиск авиабилетов по направлениям, датам и классам обслуживания;
- Фильтрация рейсов по цене, длительности, пересадкам и классам с сортировкой;
- Интерактивная схема салона самолёта (выбор посадочного места у окна, у прохода, бизнес/эконом);
- Корзина билетов с расчетом сервисного сбора;
- Оформление заказа с выбором дополнительных услуг (страховка, трансфер, питание, SMS);
- Страница подтверждения заказа с генерацией **электронного билета и QR-кода** для прохождения контроля в аэропорту;
- Личный кабинет пассажира с историей всех бронирований, просмотром билетов и редактированием профиля;
- Панель администратора с добавлением/удалением рейсов (товаров) и управлением заказами и ролями пользователей.

## 🗄 База данных и схема таблиц

В качестве основной базы данных используется встроенная легковесная **SQLite3** (хранится в файле `database/ufavia.db`), что гарантирует моментальный запуск проекта на любом ПК с PHP без необходимости предварительной настройки СУБД MySQL.  
При необходимости развертывания на MySQL/MariaDB в файле `database/schema.sql` предоставлен стандартный SQL-дамп.

### 1. Таблица `users` (Пользователи)
| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER PK AUTOINCREMENT | Уникальный идентификатор |
| `name` | VARCHAR(255) | Полное имя (ФИО) |
| `email` | VARCHAR(255) UNIQUE | Email (логин) |
| `phone` | VARCHAR(50) | Номер телефона |
| `password` | VARCHAR(255) | Хэш пароля (`PASSWORD_DEFAULT`) |
| `role` | VARCHAR(50) | Роль: `'admin'` или `'user'` |
| `created_at` | DATETIME | Дата и время регистрации |

### 2. Таблица `flights` (Товары / Рейсы)
| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER PK AUTOINCREMENT | ID рейса |
| `flight_number` | VARCHAR(50) | Номер рейса (например, `SU-1234`) |
| `airline` | VARCHAR(100) | Авиакомпания (`Аэрофлот`, `S7`, `Победа` и др.) |
| `airline_code` | VARCHAR(10) | Код IATA (`SU`, `S7`, `DP`) |
| `origin` / `origin_code` | VARCHAR | Город и код вылета (`Уфа` / `UFA`) |
| `destination` / `destination_code` | VARCHAR | Город и код прилета (`Москва` / `SVO`) |
| `departure_date` | DATE | Дата вылета |
| `departure_time` / `arrival_time` | VARCHAR | Время вылета и прилета |
| `duration` | INT | Длительность перелета в минутах |
| `price` | INT | Базовая стоимость билета (в рублях) |
| `seats_total` | INT | Всего мест на борту (по умолчанию 180) |
| `seats_available` | INT | Доступно свободных мест |
| `cabin` | VARCHAR(50) | Класс обслуживания (`economy`, `business`) |
| `stops` | INT | Количество пересадок (0 — прямой) |

### 3. Таблица `orders` (Заказы)
| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER PK AUTOINCREMENT | ID заказа |
| `order_number` | VARCHAR(50) UNIQUE | Номер заказа (например, `#UF-2026-00815`) |
| `user_id` | INT NULL | ID зарегистрированного пользователя |
| `passenger_name` | VARCHAR(255) | ФИО пассажира |
| `passenger_email` | VARCHAR(255) | Email пассажира |
| `passenger_phone` | VARCHAR(50) | Номер телефона |
| `passenger_passport` | VARCHAR(100) | Серия и номер паспорта |
| `passenger_dob` | VARCHAR(50) | Дата рождения |
| `insurance`, `transfer`, `meal`, `sms` | INT | Стоимость выбранных доп. услуг |
| `service_fee` | INT | Сервисный сбор (150 ₽ за билет) |
| `total_amount` | INT | Итоговая сумма заказа |
| `payment_method` | VARCHAR(100) | Способ оплаты |
| `delivery_method` | VARCHAR(100) | Способ получения билета |
| `status` | VARCHAR(50) | Статус (`Оплачен`, `В обработке`, `Отменён`, `Завершен`) |

### 4. Таблица `order_items` (Состав заказа / Билеты)
Привязывает конкретные билеты и выбранные места в самолёте к заказу.

### 5. Таблица `cart` (Корзина)
Хранит билеты текущей сессии пассажира до момента подтверждения и оплаты.

## 👥 Роли пользователей и тестовые доступы

В системе реализовано разграничение прав доступа по трем ролям:
1. **Гость (`guest`)**: неавторизованный пользователь. Может искать билеты, фильтровать рейсы, выбирать места в салоне, добавлять их в корзину и оформлять заказ.
2. **Пользователь (`user`)**: зарегистрированный пассажир. Имеет доступ в Личный кабинет, видит историю своих бронирований, сохраненные посадочные талоны с QR-кодами и может редактировать свои контактные данные.
3. **Администратор (`admin`)**: имеет доступ к полной панели управления `/pages/admin.php`. Может добавлять новые рейсы в базу, удалять рейсы, просматривать все заказы клиентов, изменять их статусы и назначать роли.

## 🚀 Инструкция по установке и запуску

Требования к серверу:
- **PHP** версии **7.2** или выше (поддерживаются 7.2, 7.3, 7.4, 8.0, 8.1, 8.2, 8.3);
- Включенные расширения PHP: `pdo`, `sqlite3`, `mbstring`.

### Вариант 1: Встроенный сервер PHP CLI (рекомендуемый)
Самый простой способ запустить проект без установки дополнительных серверов:
1. Откройте терминал в папке с проектом:
   ```bash
   cd /путь/к/проекту
   ```
2. Запустите встроенный сервер с маршрутизатором:
   ```bash
   php -S 0.0.0.0:3000 router.php
   ```
3. Откройте в браузере: `http://localhost:3000`

Либо, если установлен Node.js:
```bash
npm run dev
```

### Вариант 2: OpenServer / XAMPP / WampServer
1. Скопируйте папку с проектом в директорию веб-сервера (например, `domains/ufavia.loc` для OpenServer или `htdocs/ufavia` для XAMPP).
2. Убедитесь, что в конфигурации `php.ini` раскомментированы строки:
   ```ini
   extension=sqlite3
   extension=mbstring
   ```
3. Откройте сайт в браузере: `http://ufavia.loc` или `http://localhost/ufavia`.

### Вариант 3: Nginx + PHP-FPM
Пример блока конфигурации для Nginx:
```nginx
server {
    listen 80;
    server_name ufavia.local;
    root /var/www/ufavia;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
    }
}
```

## 🔄 Маршрутизация и сценарии пользователя

1. **Главная (`index.php`)**:
   - Ввод направления («Уфа» → «Москва»), даты и класса перелета.
   - Нажатие «Найти билеты» перенаправляет на `pages/search.php`.
2. **Результаты поиска (`pages/search.php`)**:
   - Пассажир видит список рейсов, количество оставшихся свободных мест, время вылета/прилета.
   - Использует фильтры по цене, пересадкам и классу.
   - Нажимает «Выбрать место» на понравившемся рейсе.
3. **Выбор места (`pages/tickets.php?flight_id=ID`)**:
   - На интерактивной схеме самолета кликает по свободному месту (например, `2B` или `1A`).
   - Итоговая сумма автоматически пересчитывается в реальном времени.
   - Нажимает «Купить авиабилет» — билет отправляется в корзину.
4. **Корзина (`pages/cart.php`)**:
   - Проверяет состав заказа, при необходимости удаляет ненужные билеты.
   - Нажимает «Перейти к оформлению».
5. **Оформление (`pages/order.php`)**:
   - Вводит ФИО, паспортные данные, телефон и email.
   - Отмечает нужные дополнительные услуги (страховка, питание, трансфер).
   - Выбирает способ доставки и оплаты.
   - Нажимает «Подтвердить и оплатить».
6. **Выдача билета (`pages/checkout.php?order_id=ID`)**:
   - Заказ автоматически записывается в базу данных.
   - Пассажир видит готовый электронный посадочный талон с **QR-кодом** и может его распечатать.
7. **Личный кабинет (`pages/profile.php`)**:
   - Вся история заказов и билеты всегда доступны в профиле.
8. **Панель администратора (`pages/admin.php`)**:
   - Администратор видит аналитику продаж, может добавить новый рейс через форму, удалить старый рейс или изменить статус любого заказа.
