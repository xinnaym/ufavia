## ✈ О проекте

**UFAvia** — интернет-магазин и сервис онлайн-бронирования авиабилетов по России и миру с базовым узлом в аэропорту г. Уфы.  
Система спроектирована без сторонних громоздких фреймворков, на чистом **PHP 7.2+** с использованием **PDO**, что гарантирует максимальную производительность, безопасность (подготовленные выражения от SQL-инъекций, хэширование паролей через `password_hash`), валидность кода и совместимость с **MySQL 5.7** в OpenServer Panel.

## 🖥 Структура типовых страниц по ТЗ (7 обязательных страниц + Панель администратора)

1. **Главная страница (`index.php`)**:
   - Логотип и фирменное название UFAvia (цветовая гамма: синий `#0867c9` + оранжевый `#ff6b2c`);
   - Интерактивная форма поиска авиабилетов (направление «Откуда / Куда», даты вылета и возврата, количество пассажиров, класс обслуживания);
   - Популярные направления и дешевые авиабилеты из Уфы (динамический вывод актуальных минимальных цен из БД MySQL);
   - Рекомендации и отзывы пассажиров;
   - Семантическое меню навигации по сайту.

2. **Страница результатов поиска (`pages/search.php`)**:
   - Список доступных рейсов и авиакомпаний («Аэрофлот», «S7», «Победа», «Utair», «Россия», «Nordwind» и др.);
   - Расписание вылетов и прилётов, длительность перелёта, стоимость билетов и актуальный остаток свободных мест на борту;
   - Фильтры поиска и сортировки рейсов: по цене (диапазоны), времени вылета, длительности, классу обслуживания и пересадкам (прямой / с пересадкой);
   - Актуальная информация о правилах бронирования авиабилетов и условиях возврата средств.

3. **Страница выбора и бронирования авиабилетов (`pages/tickets.php`)**:
   - Детальная информация о выбранном рейсе, авиакомпании, времени в пути;
   - **Интерактивная схема салона самолёта** с выбором посадочных мест (у окна, у прохода, бизнес/эконом класс);
   - Динамический пересчёт стоимости билета в реальном времени;
   - Кнопка «Купить авиабилет», переносящая выбранный билет в корзину для заключения договора.

4. **Корзина билетов (`pages/cart.php`)**:
   - Список выбранных билетов с указанием рейса, маршрута, даты, времени, выбранного места в салоне и стоимости;
   - Расчёт сервисного сбора (комиссионные) и итоговой стоимости;
   - Возможность удаления ненужного билета или полной очистки корзины;
   - Переход к процедуре оформления заказа.

5. **Оформление заказа (`pages/order.php`)**:
   - Подтверждение информации о заказе (маршрут, даты, стоимость, число билетов);
   - Форма ввода персональных данных пассажиров (ФИО, дата рождения, серия и номер паспорта, контактный email и телефон);
   - Дополнительные услуги: медицинская страховка в полёте, индивидуальный трансфер из/в аэропорт, горячее бортовое питание, SMS-информирование о статусе рейса;
   - Выбор способов оплаты и получения билетов.

6. **Страница подтверждения заказа и оплаты (`pages/checkout.php`)**:
   - Сводная информация о заказе и пассажирах;
   - Подтверждение оплаты и выдачи маршрутной квитанции;
   - Сгенерированный **электронный посадочный талон с QR-кодом и штрих-кодом** для прохождения контроля в аэропорту;
   - Функция отправки на печать (Print) адаптированная под формат A4.

7. **Личный кабинет пассажира (`pages/profile.php`)**:
   - История бронирования авиабилетов пассажира со статусами («Оплачен», «В обработке», «Отменён»);
   - Просмотр электронных билетов на следующие рейсы;
   - Контактные данные, привязанные к бронированиям;
   - Настройки профиля: изменение ФИО, email, телефона и пароля.

8. **Панель управления администратора (`pages/admin.php`)**:
   - Дашборд статистики: общее число рейсов, заказов, зарегистрированных пользователей и сумма выручки;
   - **Управление товарами (рейсами)**: форма добавления нового авиарейса в БД с валидацией;
   - Удаление рейса из базы данных;
   - Просмотр всех заказов клиентов и изменение их статусов;
   - Управление ролями зарегистрированных пользователей (назначение роли `admin` или `user`).

## 🚀 Инструкция по запуску в OpenServer Panel

Проект полностью настроен для работы в **OpenServer Panel** под управлением **PHP 7.2+** и **MySQL 5.7**.

### Шаг 1. Размещение проекта
1. Скопируйте папку с проектом в директорию доменов OpenServer:
   - Для OpenServer 5.x: `[диск]:\OpenServer\domains\ufavia`
   - Для OpenServer 6.x: `[диск]:\OSPanel\home\ufavia`

### Шаг 2. Настройка модулей в OpenServer
1. В трее нажмите правой кнопкой мыши на флажок OpenServer → **Настройки** → вкладка **Модули**:
   - **HTTP**: `Apache_2.4-PHP_7.2-7.4` (или `Nginx` / `Apache_2.4-PHP_8.0-8.3`)
   - **PHP**: `PHP_7.2`, `PHP_7.3`, `PHP_7.4`, `PHP_8.0`, `PHP_8.1`, `PHP_8.2` или `PHP_8.3`
   - **MySQL**: `MySQL-5.7` (или `MySQL-8.0` / `MariaDB-10.3`)
2. Нажмите кнопку **«Сохранить»** и **«Запустить сервер»** (зеленый флажок).

### Шаг 3. База данных
Параметры подключения по умолчанию настроены в файле `includes/config.php`:
```php
define('DB_HOST', '127.0.0.1');     // Хост
define('DB_PORT', '3306');          // Порт
define('DB_NAME', 'ufavia');        // Имя базы данных
define('DB_USER', 'root');          // Пользователь по умолчанию
define('DB_PASS', '');              // Пароль по умолчанию пустой
```

#### Способ А (Автоматический — рекомендуется):
Просто откройте сайт в браузере! Скрипт `includes/db.php` при первом обращении:
1. Автоматически создаст базу данных `ufavia` в MySQL 5.7;
2. Автоматически создаст все 5 таблиц с кодировкой `utf8mb4` и внешними ключами `InnoDB`;
3. Автоматически наполнит базу актуальными авиарейсами, начальными учетными записями и заказами.

#### Способ Б (Через PhpMyAdmin):
1. Откройте PhpMyAdmin в OpenServer (меню флажка → **Дополнительно** → **PhpMyAdmin**);
2. Логин: `root`, пароль: пустой (нажмите «Вперёд»);
3. Перейдите во вкладку **«Импорт»**;
4. Выберите файл `database/ufavia.sql` из папки проекта и нажмите кнопку **«Вперёд»**.

### Шаг 4. Открытие сайта
Откройте в адресной строке любого браузера:
```text
http://ufavia/
```
или
```text
http://localhost/
```

## 🗄 База данных и схема таблиц (MySQL 5.7)

Дампы базы данных находятся в папке `database/`:
- `database/ufavia.sql` — полный SQL-дамп со схемой и начальными демонстрационными данными;
- `database/schema.sql` — чистая структура таблиц MySQL 5.7 (DDL).

### 1. `users` — Пользователи системы
| Поле | Тип | Описание |
|---|---|---|
| `id` | INT AUTO_INCREMENT PK | Уникальный ID |
| `name` | VARCHAR(255) | ФИО пользователя |
| `email` | VARCHAR(255) UNIQUE | Email (логин) |
| `phone` | VARCHAR(50) | Телефон |
| `password` | VARCHAR(255) | Хэш пароля (`password_hash`) |
| `role` | VARCHAR(50) | Роль: `'admin'` или `'user'` |
| `created_at` | TIMESTAMP | Дата и время регистрации |

### 2. `flights` — Рейсы (товары магазина)
| Поле | Тип | Описание |
|---|---|---|
| `id` | INT AUTO_INCREMENT PK | ID рейса |
| `flight_number` | VARCHAR(50) | Номер рейса (например, `SU-1234`) |
| `airline` | VARCHAR(100) | Название авиакомпании |
| `airline_code` | VARCHAR(10) | IATA-код компании (`SU`, `S7`, `DP`, `UT` и др.) |
| `origin` / `origin_code` | VARCHAR | Пункт отправления (`Уфа` / `UFA`) |
| `destination` / `destination_code` | VARCHAR | Пункт назначения (`Москва` / `SVO`) |
| `departure_date` | DATE | Дата вылета |
| `departure_time` | VARCHAR(20) | Время вылета |
| `arrival_time` | VARCHAR(20) | Время прилёта |
| `duration` | INT | Длительность перелёта в минутах |
| `price` | INT | Стоимость билета в рублях |
| `seats_total` | INT | Всего мест в салоне |
| `seats_available` | INT | Количество свободных мест на борту |
| `cabin` | VARCHAR(50) | Класс обслуживания (`economy`, `business`) |
| `stops` | INT | Количество пересадок (0 — прямой) |

### 3. `orders` — Заказы авиабилетов
| Поле | Тип | Описание |
|---|---|---|
| `id` | INT AUTO_INCREMENT PK | ID заказа |
| `order_number` | VARCHAR(50) UNIQUE | Номер заказа (`UF-2026-XXXXX`) |
| `user_id` | INT NULL FK | Связь с `users(id)` |
| `passenger_name` | VARCHAR(255) | ФИО пассажира |
| `passenger_email` | VARCHAR(255) | Email пассажира |
| `passenger_phone` | VARCHAR(50) | Телефон |
| `passenger_passport` | VARCHAR(100) | Паспортные данные |
| `passenger_dob` | VARCHAR(50) | Дата рождения |
| `insurance`, `transfer`, `meal`, `sms` | INT | Дополнительные услуги |
| `service_fee` | INT | Сервисный сбор (150 ₽ за билет) |
| `total_amount` | INT | Итоговая стоимость заказа |
| `payment_method` | VARCHAR(100) | Способ оплаты |
| `delivery_method` | VARCHAR(100) | Способ получения билетов |
| `status` | VARCHAR(50) | Статус (`Оплачен`, `В обработке`, `Отменён`) |

### 4. `order_items` — Состав заказа
Хранит билеты, привязанные к заказу, с указанием конкретного выбранного места в салоне самолёта (`seat_number`, например `2B`).

### 5. `cart` — Корзина покупок
Хранит билеты текущей сессии пассажира до момента оформления.

## 👥 Роли пользователей и тестовые доступы

В проекте реализовано разграничение прав доступа для 3 ролей:
1. **Гость (`guest`)**: неавторизованный посетитель. Доступны: поиск авиабилетов, фильтрация, интерактивный выбор мест в салоне, добавление в корзину и оформление заказа.
2. **Зарегистрированный пассажир (`user`)**: доступ в Личный кабинет (`pages/profile.php`), просмотр истории своих билетов, сохранение посадочных талонов с QR-кодами, редактирование персональных данных.
3. **Администратор (`admin`)**: полный доступ к панели управления (`pages/admin.php`). Может добавлять новые рейсы, удалять рейсы, изменять статусы любых заказов и назначать роли.
